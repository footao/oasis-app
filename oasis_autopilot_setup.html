動かないときの切り分け

上から順に試すと、どこで止まっているか1分で分かります。

手順1 — まずこれが動くか

いちばん短いブックマークレットです。これが動かなければ原因は私のコードではありません（Safariの登録ミスか、サイト側のCSP）。

🔍 診断（585文字）

緑の枠が出た場合 → ブックマークレット自体は動きます。手順2へ。
何も起きない場合 → 次のどちらかです。
・Safariが javascript: を消した…登録し直してください。URL欄に貼ったあと、先頭が javascript: で始まっているか確認を。消えていたら手で打ち足します。
・サイトのCSPがブロック…この場合ブックマークレット方式は使えません。下の「最終手段」へ。

手順2 — ローダー版（推奨）

本体を外部に置き、238文字だけ登録します。18,000文字を貼る必要がなくなり、コードを更新してもブックマークの登録し直しが不要になります。

🛩 オートパイロット（ローダー）

先に1回だけ準備が要ります。 autopilot.bundle.js をリポジトリ直下に置いて GitHub に push してください。
読み込み先: https://cdn.jsdelivr.net/gh/footao/oasis-app@main/autopilot.bundle.js
リポジトリ名やブランチが違う場合は、下のコード内のURLを書き換えてから登録してください（@main がブランチ名）。

手順3 — 全部入り（従来版）

外部に置きたくない場合はこちら。18,193文字あるので、iOSでは登録に失敗することがあります。

最終手段 — CSPで弾かれる場合

ブックマークレットが一切動かないサイトでは、次のどちらかになります。

PCChrome拡張の Tampermonkey にバンドルを登録（CSPの影響を受けません）
iOSSafari拡張の Userscripts（App Store・無料）にバンドルを登録

どちらも「対象サイトで実行するスクリプト」として autopilot.bundle.js の中身をそのまま貼れば動きます。

それでも動かないとき

Safari の 設定 → Safari → 詳細 → Webインスペクタ をオンにし、Macがあれば繋いでコンソールのエラーを見てください。無ければ、手順1の診断結果と「パネルが出るのか／出ないのか」「ログに何が出ているか」を教えてください。
