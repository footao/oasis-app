必要スタミナ早見表

実測 999頭（ステータスは Discordログ、消費は result API の timeline）。スタミナは「速さの燃料」で、余った分は完全に無駄になります。

仕組み　残スタミナ ＝ 初期スタミナ − Σ(100mごとの消費)。消費は速いほど増えるので、速い馬ほど多くのスタミナが要ります。足りなくなると最後に減速します（余っても速くはなりません）。実測で 98.3% の馬がこの式どおりでした。
