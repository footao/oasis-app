1. 全体の流れ

① 実効ステータス = 素ステータス × コンディション × Σパッシブ倍率 × Σ装備・お守り倍率 ② レート = 定数 × Σ区間 Σstat( 区間重み[区間][stat] × 距離バランス[距離][stat] × 実効stat ) × 疲労補正 ③ スタミナ = floor(実効スタミナ) − Σ(100mごとの消費) ④ 疲労補正 = f(スタミナ収支) 収支 = 持ちスタミナ − 必要スタミナ ⑤ 最終スコア = レート系の積算（タイム基準・2026/07/28 のパッチ以降） ⑥ 実効ステータスにはレースごとに ±1.5% の乱数が乗る

4. スタミナ消費の法則

消費/100m = clamp( c[距離] × ( 実効SP×0.60×bal[0] + 実効PW×0.30×bal[1] + 実効ST×0.10×bal[2] ), 下限, 上限 ) 必要スタミナ = 消費/100m × 区間数 不足 = max(0, 必要 − 持ち) 余り = max(0, 持ち − 必要)
距離c下限上限区間数必要ST の幅実務上の目安

マイル0.019702.2343.0671534〜46クランプ張り付き多数。46あれば確実
中距離0.030652.5413.7372051〜75速い馬ほど上限に張り付く
長距離0.041092.5703.6802564〜9287で息切れ消滅／93〜95が最良／96+は余剰
速いほど消費が増える。 消費は「実効ステータスの一次式」なので、SPEEDを上げるとスタミナ切れが早まる。レートが上限に当たると消費も上限に張り付く。
実例: レート207.9で最速だった馬が必要46に対し持ち43で −3.0 → 自分の速さでスタミナ切れを起こして3着。

6-d. 分散系（着順のブレに作用）

スキル効果扱い
安定感速度のばらつきが約半分σ倍率 0.5 （ステータスには一切効かない）
粘り腰スタミナ不足による速度低下を20%軽減倍率化できないため実ログから学習
σ倍率 = √( VARIANCE_SHARE × m² + (1 − VARIANCE_SHARE) ) VARIANCE_SHARE = 0.5
σ全体のうち半分だけが「ゲーム側の乱数」で、残りはモデルの推定誤差。分散低減スキルはゲーム側の分にしか効かない。乱数幅は 1.5%（2026/08 に一時 3% → 2026/08/17 に 1.5% へ差し戻し）。

8. コンディション

好調×1.0000+0.0121 (n=1,783)+0.0020

コンディションはステータスに乗算されない。 timeline の初期スタミナ ÷ (素スタミナ+装備加算) を全1,717頭で取ると、好調・不調とも中央値が ちょうど 1.0000。
初期スタミナに現れる 0.89〜1.19 の係数はすべてパッシブ由来: スピードスター ST×0.90（実測 0.8936）／同族嫌悪 ×1.20（実測 1.1884）／各種得意 ×1.15（実測 1.1463）／脳筋+パワー大アップ ×1.0000。
実スコアでは 好調 と 不調 で約 3.4% の差が出るが、ステータスを統制したモデル係数は +0.002 / +0.004 とほぼ 0。コンディション単体の効果は測れていない（強い個体が好調になりやすい等の交絡の可能性が高い）。

表示オッズのバグ（2026/08/15 開発者確認済み・未修正）
プール総額の表示には初期プール金 200,000 rrc が含まれているが、購入画面のオッズは (プール総額 − 200,000) を分子にして計算されている。払戻はプール総額から出るので、実際の払戻 = 表示オッズ × P / (P − 200,000)。
プール30万なら3.0倍、100万なら1.25倍、500万なら1.04倍。プールが小さいほど差が大きい。
また表示プール0は「まだ誰も買っていない」状態で、実際には20万ある（誰かが1口買った瞬間 0 → 21万 に切り替わる）。
