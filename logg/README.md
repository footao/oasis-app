# logg/ — 学習用ログの置き場

Discordエクスポートの `.txt` をここに入れてください。アプリの既定の学習データ源です。

## ⚠ 公開リポジトリに置く場合の注意

Discordエクスポートには **実ユーザー名（@ハンドル）が含まれます**。
リポジトリを public にするなら、次のどれかを選んでください。

1. リポジトリを private にする（いちばん簡単）
2. `@` 以降を伏せてからコミットする
3. `logg/` を `.gitignore` に入れ、学習データは Google ドライブ経由にする
   （`drive_backend.py` が対応済み。secrets に `[gdrive]` を設定）

**学習に owner 列は使っていない**ので、伏せ字にしても精度は落ちません。
